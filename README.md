# 윤예진 포트폴리오

GitHub Pages로 배포되는 정적 포트폴리오입니다.

## 배포

1. 이 저장소를 GitHub에 올립니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택합니다.
3. `main` 브랜치에 push하면 `.github/workflows/pages.yml`이 `dist` 폴더를 자동 배포합니다.

## 로컬 확인

`dist/index.html`을 브라우저에서 열거나 `dist` 폴더를 정적 서버로 실행합니다.
